# 本地 RAG 问答 Agent —— 代码复现（准备 / 检索 / 生成 三层）

纯标准库，无外部模型依赖，三段脚本各自 `--self-test` 全绿。

## 数据源（本目录全部为合成，可离线复现）

| 数据 | 内容 | 用途 |
| --- | --- | --- |
| `rag_core.py` 内 `DOC`（01） | 一篇「退款政策」短文，核心句「七天无理由退款」 | 复现切分错位 / 版本漂移 / 持久化损坏 |
| `DOCS`（02） | 4 条知识库片段，只覆盖「退款 / 物流」，没有「发票」 | 复现查询词不匹配（空窗）/ 上下文溢出 |
| `recs`（03） | 2–3 条片段映射 | 复现幻觉编造引用 |

真实使用时把上面这些换成你自己的文档集合即可；脚本逻辑不变。

## 文件职责

- `rag_core.py`：共享内核。哈希 Embedder（`version` 不同 => 向量空间不同，模拟漂移）、两种切分策略、
  向量库 JSON 持久化 + 损坏自动重建、建索引与余弦检索。
- `01_rag_prep.py`：**准备层**。复现 ①②③：
  - ① 切分错位：`fixed` 硬切切断核心句，`sentence` 保留语义边界
  - ② embedding 版本漂移：索引用 v1、查询用 v2，同一句话余弦=0，top1 答错
  - ③ 向量库损坏：落盘文件被截断 → `load_or_rebuild` 从源文档重建
- `02_rag_retrieve.py`：**检索层**。复现 ④⑤：
  - ④ 查询词与文档词不匹配：域外问题命中空窗（宁可返回「我不知道」）
  - ⑤ 上下文窗口溢出截断：预算只够前 2 段，把排名第 3 的关键 chunk 挤掉
- `03_rag_generate.py`：**生成层**。复现 ⑥：幻觉编造引用 + 两道防线（引文合法性 / 引文与答案关键词重叠）

## 运行

```bash
python3 01_rag_prep.py --self-test
python3 02_rag_retrieve.py --self-test
python3 03_rag_generate.py --self-test
```

输出末尾出现 `ALL_SELFTESTS_PASSED` 即全部通过。

## 各阶段输出含义

- 01：打印切分计数、`同版/跨版` 余弦、损坏重建的 chunk 数、索引查询一致性得分。
- 02：打印空窗判定、预算截断前后关键 chunk 是否在场、正常召回的 top1。
- 03：打印忠实答案通过、编造引用被拦截、无关引用被拦截、无防护对照漏出。

## 换真实业务改哪里（最小改动）

- **Embedder** → 换成真模型（sentence-transformers / 通义 / OpenAI embedding），保持 `embed(text)->向量` 接口；
  注意：索引与查询必须同一模型同一版本，否则就是坑 ②。
- **VectorStore** → 换成 FAISS / Milvus / PGvector，保持 `save/load_or_rebuild` 接口；
  真实向量库同样要处理损坏与重建（坑 ③）。
- **切分策略** → 换成按标题 / 按语义分块，但要守住「不切断核心概念」这条线（坑 ①）。
- **grounding 两道防线** → 接在真 LLM 输出之后，答案未通过校验就回退到「检索结果没说」或直接拒答（坑 ⑥）。
