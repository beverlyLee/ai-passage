# DeepSeek 刚开源就涨价4倍 我连夜装好 发现一件细思极恐的事

我昨晚十一点多刷到那个黑色鲸鱼的时候，手比脑子快。

直接打开了终端。

```
npx @deepseek-ai/dsh web
```

然后浏览器弹出一个本地页面。127.0.0.1 冒号 3080。鲸鱼是黑的。不是平时那个蓝的。我当时心里就咯噔一下。这事儿，不对劲。

DeepSeek 终于不只会聊天了。

它给那个聪明的大脑，装上了手和脚。名字叫 DeepSeek Harness。8 月 13 号晚上刚开源。MIT 协议。代码全摊在 github 上。

官方给了一个特别朴素的公式。模型是大脑，Harness 是身体，合起来才叫 Agent。

说人话。以前你问 DeepSeek 一个问题，它给你一段答案，剩下的活儿你自己干。现在你跟它说，去把我这个仓库的 bug 修了，顺手提交个测试报告。它就真去拉代码，找问题，改，跑测试，最后把结果甩给你。全程你不用动。

这玩意儿发布 12 个小时，github 星标破了五万。史上增长最快的项目之一。一个做内测的网友原话是，体验两天，我愿称它为宇宙最强。

你品。你细品。

但真正让我后脊梁发凉的，不是它多强。是 DeepSeek 在同一天，干的另一件事。

涨价。

就在开源的那天，官方悄咪咪发了个定价公告。V4 Pro 的峰时输出价，从每百万 token 零点八七美元，直接干到三点九六美元。翻了四点五五倍。

一边把代码白送你。一边把水龙头拧到最紧。

这算盘，打得也太响了。

我一开始觉得，这不精神分裂吗。后来看了时间线才反应过来。8 月 12 号，V4 Pro 转正。8 月 13 号，Harness 开源，同天涨价。这三件事不是碰巧，是一套组合拳。

它想明白了。光卖 token 不赚钱，也守不住。真正值钱的，是让模型跑起来的那套系统。也就是 Harness。

现在大家都在说一个词，模型加 Harness 等于 Agent。以前比谁的模型参数大，比谁跑分高。以后比的是，谁的系统能让模型老老实实干活，干一上午不崩，干一天不出错。

DeepSeek 这一手，等于把竞争从模型层，拽到了工程层。

它甚至不锁死你用谁家的模型。你可以用 DeepSeek，也可以接 Claude，接 OpenAI，接一堆别的。它的哲学是一切皆插件。大脑能换，工具能换，连界面都能换。像一个乐高工具箱，你爱怎么拼怎么拼。

内测那次招聘更狠。团队负责人在 X 上喊了一嗓子，要开源 Agent 项目的开发者来报名。四十八小时。七百六十九个人带着七百一十二个仓库涌进来。加起来一百二十多万颗星。评论区直接变成了行业招聘现场。

你看出来没有。DeepSeek 不是在招人。它是在扫货。把整个 Agent 生态里能干活的开发者，一把搂进自己的阵营。

回到那个黑色鲸鱼。

我记得 DeepSeek 以前的 logo 是蓝鲸。温和，安静，像个只管思考的脑子。现在这个黑的，网上有人叫它鲸鱼侠。完整体的鲸鱼侠。脑子里有大脑，身上有手脚，能下水能上岸。

我觉得这形容特别准。

一个只聊天的 AI，再聪明也是个顾问。你问一句它答一句，活儿还是你的。一个装了 Harness 的 AI，是个能上手干活的同事。你给它目标，它给你结果。

这才是国货 AI 真正让人激动的地方。不是又发了个新模型，参数又涨了多少。是它终于开始认真琢磨，怎么让 AI 真正替人把事儿办了。

开源加涨价这步棋，短期看像在劝退白嫖党。长期看，是在给自己的生态筑墙。墙筑好了，里面的人越聚越多，外面的人想进来，就得按它的规矩走。

细思极恐的地方就在这。

我们以为自己在围观一个工具开源。其实我们在围观一个时代换挡。从比大脑，到比手脚。从卖算力，到卖生产力。

那个黑色鲸鱼游进来的时候，水花不大。但我估计，等浪打过来的时候，很多人会发现自己还没上船。

你，上船了吗。
